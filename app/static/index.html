Chaque modèle s'installe en un clic, génération et édition d'image comprises.

1. Moteur (stable‑diffusion.cpp)

    

    

      
      
    

    
Le binaire officiel précompilé est téléchargé depuis GitHub. NVIDIA → cuda (recommandé),
      AMD/Intel/autres → vulkan. Vous pouvez aussi copier votre propre sd-cli dans le dossier bin/.

  


  

    
2. Modèles 

    
Choisissez la quantification puis cliquez sur Tout télécharger : les fichiers manquants
      sont téléchargés à la suite, et le modèle devient actif. Tout fichier .gguf/.safetensors
      copié manuellement dans models/<modèle>/<catégorie>/ apparaît aussi automatiquement
      (fine‑tunes, autres quantifications…), sélectionnable par bouton radio.
