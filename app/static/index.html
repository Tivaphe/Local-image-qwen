Configuration


  

    
1. Moteur (stable‑diffusion.cpp)

    

    

      
      
    

    
Le binaire officiel précompilé est téléchargé depuis GitHub. NVIDIA → cuda (recommandé), AMD/Intel/autres → vulkan. Vous pouvez aussi copier votre propre sd-cli dans le dossier bin/.

  


  

    
2. Télécharger un modèle 

    
Un seul clic télécharge tous les fichiers du modèle : diffusion + encodeur de texte + VAE
      (+ encodeur de vision pour l'édition d'image). Le téléchargement reprend où il s'est arrêté :
      les fichiers déjà présents sont ignorés.

    

  


  

    
3. Fichiers de modèles — détail (avancé)

    
Pour choisir vous-même une quantification, cliquez « Télécharger » sur un fichier précis.
      Tout fichier .gguf/.safetensors copié manuellement dans
      models/<modèle>/<catégorie>/ apparaît automatiquement — y compris vos propres
      variantes (fine‑tunes, autres quantifications) du modèle de diffusion, sélectionnables par le bouton radio.
